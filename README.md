# Visuels 1tempor'ELLE

Images des vêtements de la boutique [1temporelle.com](https://www.1temporelle.com),
hébergées ici pour être affichées sur les fiches produit.

**Pourquoi ce dépôt.** Le stockage d'images de la boutique n'est pas configuré
côté serveur : aucune photo ne peut y être envoyée. Ce dépôt sert d'hébergement
en attendant, et disparaîtra le jour où le stockage sera réglé.

## Ce qu'on y trouve

`imperial/` : 21 visuels d'ambiance des pièces de la collection
Imperial automne-hiver 2026, un par référence.

**Ce sont des visuels d'ambiance**, fabriqués à partir de la photo du
fabricant : ils montrent l'esprit du vêtement porté, pas la pièce elle-même.
La photo de référence, sur la fiche produit, fait foi pour la coupe et le
coloris.

## Comment les appeler

```
https://cdn.jsdelivr.net/gh/groupelespadon-cpu/1temporelle-visuels@main/imperial/<reference>.webp
```
